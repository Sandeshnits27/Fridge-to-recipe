# Fridge-to-recipe

This project follows the PDF assignment for a small React app that turns a free-form ingredient list into a structured recipe generated by an AI model.

## What it does

- Accepts a free-form ingredient list in a text area.
- Sends the list to a real LLM through a backend route.
- Parses the returned JSON and renders a recipe as interactive UI.
- Lets the user adjust servings and track each cooking step with a checklist.
- Handles bad model output, slow requests, and empty or failed responses without crashing.

## Setup

1. Install dependencies:
   npm install
2. Create a `.env` file from `.env.example` and add your API key.
3. Start the app:
   npm start
4. Open the app in the browser at http://localhost:5173

## AI usage note

This project uses OpenRouter with the `openai/gpt-4o-mini` model. The API key is kept on the backend and never shipped to the browser.

I used AI assistance to help draft the implementation and guide the failure-handling logic, while keeping the app behavior and requirements aligned to the assignment.

## Known limitations

- The model can still return low-quality output, so the backend validates the JSON shape before rendering.
- Smaller or slower models may need a retry or a clearer ingredient list.
- Free-tier API limits can restrict how often the app can generate results.
